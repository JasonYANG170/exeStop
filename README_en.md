Program cannot be closed? Want to close a program regularly? Don't want the program to start secretly? Don't want others to use programs on your computer?

Come and try it!
# Features
- ✅Scheduled application termination
- ✅Close the program directly
- ✅ Disable program startup

# Instructions for use
1. Find the program, right-click Properties, and find the program name ending with ".exe" in the path.

2. Fill in the name into the application closing assistant.

3. Click Settings (time is optional).

4. Select the function you need
